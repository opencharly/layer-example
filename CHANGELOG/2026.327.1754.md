|---|---|---|---|

| `hello-web` | checks that travel with the artifact, in both phases | the system Python (`arch` → `python`, `fedora` and `"debian,ubuntu"` → `python3`); `/srv/hello/hello` and `/srv/hello/health`, written by `write:` steps; the `hello-web` service on port 8080 | the page is in the artifact (`file`), and the running server answers `GET /hello` with 200 and `hello` (`http`, runtime context, `eventually: 30s`) |
